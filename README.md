# Agencia_Llanquihue_Tour

## Descripción
Proyecto en Java para la digitalización de operaciones de la agencia de turismo "Llanquihue Tour". El sistema permite organizar y clasificar de forma estructurada a las personas vinculadas a la empresa(Clientes y Empleados) mediante el uso de POO.

## Estructura
# `cl.duoc.llanquihuetour.model`
- `Direccion` : Clase que representa la dirección física.
- `Persona` : Clase que encapsula los datos personales de un individuo.
- `Empleado` : Clase que hereda de `Persona` e incluye atributos específicos en relación a los empleados.
# `cl.duoc.llanquihuetour.app`
- `Main`: Clase principal del cual se ejecuta el proyecto.

## Instrucciones de uso 
- Abre el proyecto en IntelliJ IDEA y ejecuta la clase `Main`.
